## Páginas desenvolvidas

As páginas desenvolvidas individualmente neste projeto foram a página de Encartes, responsável pela apresentação das promoções do supermercado, e a página de Dicas, destinada à apresentação de conteúdos informativos aos consumidores.

Também fui responsável pelo desenvolvimento da `Navbar` utilizada nas páginas do projeto.

Como líder do grupo, fiquei responsável pela organização da equipe, integração dos códigos desenvolvidos pelos integrantes e padronização visual das páginas, buscando garantir a consistência das interfaces, a responsividade e o funcionamento da navegação do website.
